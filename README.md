## Environment Setup and Dependencies
1. First create a virtual environment by using the command in the terminal: `python -m venv .venv`.
2. Activate the environment by using the command in the terminal: `.venv\Scripts\activate` for Windows or `source .venv/bin/activate` for MacOS/Linux.
3. Install the packages using the commands in the terminal: `python -m pip install --upgrade pip` followed by `python -m pip install torch torchvision torchmetrics numpy torch-fidelity`.

## How to Run the Code
Each .py file is meant to run separately. To test each file, run the command `python [filename.py]`.

For example, if I want to run `q1response.py`, I will run this command `python q1response.py` in the terminal.
